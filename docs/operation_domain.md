# スタッフ間コミュニケーションコンテキスト

## 責務

- スタッフ間連絡・情報共有（スタッフ↔スタッフ）
- スタッフ→システムの運用操作（配置）
- テナント内集約（履歴ダイジェスト・フィードバック蓄積）を保護境界内で担う
- スタッフアプリへの配送を接続状態で分岐（開＝リアルタイム配信へ push 委譲／閉＝通知をトリガー）
- ゲスト向けメッセージのゲストコンテキストへの供給（push。ゲスト側が読み取りモデルとして保持）
- 手動介入（危険フラグ等）と運用状態の変更（ゲート開閉・観測点設定変更）は誘導への介入として誘導ドメインに属し、本コンテキストの外にある

## ドメインモデル

| 語 | 英語 | 内容 |
|---|---|---|
| オペレーション | Operation | 手動操作のハンドリング |
| スタッフメッセージ | Staff Message | スタッフ間・ゲスト向けメッセージ |
| 配置／配置替え | Assignment / Reassignment | スタッフの担当箇所（観測点・ゲート・任意のグラフ要素）の割当と変更<br>同一の配置先に複数のスタッフを置ける<br>ルート途中は配置位置（比率。表示用途のみ）<br>参照するのはゲート地点（設計層の ID）であり開閉状態ではない |
| 提案配信 | Proposal Delivery | 提案・行列案内をスタッフ（アプリ）へ配る<br>ゲストへの誘導情報はスタッフがゲスト向けメッセージとして手動配信 |
| リアルタイム配信 | Realtime Delivery | 開アプリへの配信（支援機構／GW経由）<br>最終更新IDによる変更通知＋pull、フォールバックはロングポーリング |
| 通知 | Notification | 閉デバイスへのFCMプッシュ（支援機構） |
| 接続状態 | Connection State | アプリ開／閉<br>配送分岐の根拠 |
| 履歴ダイジェスト／フィードバック蓄積／匿名化 | History Digest / Feedback Accumulation / Anonymization | テナント内集約と境界前匿名化<br>匿名化はテナント識別子の除去と、値の上下パーセンタイルでの丸め込み |

クロステナント集約（参照値集約）は別コンテキストが担う。

## ドメインイベント

| 区分 | イベント |
|---|---|
| スタッフ↔スタッフ | スタッフメッセージ送信された / StaffMessageSent<br>スタッフメッセージ取り下げられた / StaffMessageRevoked<br>誘導情報共有された / GuidanceInfoShared |
| 運用操作 | 配置替え指示された / ReassignmentDirected<br>配置変更がシステム反映された / ReassignmentApplied |
| 接続状態 | アプリ接続された / AppConnected<br>アプリ切断された / AppDisconnected |
| 配送 | 配送振り分けされた / DeliveryRouted<br>リアルタイム配信された / RealtimeDelivered<br>プッシュ通知送信された / PushNotificationSent<br>プッシュ通知配信失敗した / PushNotificationFailed |
| テナント内集約 | 履歴ダイジェスト集約された / HistoryDigestAggregated<br>フィードバック値蓄積された / FeedbackAccumulated<br>フィードバック値匿名化された / FeedbackAnonymized |

## 不変条件

- テナント内集約は保護境界内に閉じる
- 境界外へ出すデータは事前匿名化
- 手動介入と運用状態の変更（ゲート開閉・観測点設定変更）は誘導ドメインに属し、本コンテキストの外にある
- 本コンテキストから観測への同期呼び出しは持たない（依存は観測→本コンテキストの一方向）
- 配送の支援機構（Realtime／Notification）は独立コンテキストにしない
- 配送は接続状態で分岐（開＝Realtime／閉＝Notification）
